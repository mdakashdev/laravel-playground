# Command

1. custom folder a request and resource likha 

```bash
php artisan make:request Api/V1/Auth/RegisterRequest
```

```bash
php artisan make:resource Api/V1/UserResource
```

2. class create korar command 

```bash
php artisan make:class Actions/Auth/RegisterUserAction
```

3. Controller তৈরি করো।

```bash
php artisan make:controller Api/V1/AuthController
```
